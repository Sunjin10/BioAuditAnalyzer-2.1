# BioAuditAnalyzer 2.0 — 분석방법

## 1. 분석 목적

OpenDART에서 수집한 공개 재무정보를 바탕으로 주요 재무지표를 계산하고, 사전 정의한 규칙에 해당하는 계정에 대해 추가 검토 신호를 생성한다.

각 신호에는 관련 회계기준과 감사자료(PBC), 검증 목적 및 검증절차를 연결한다.

## 2. 분석 대상 및 기준

- 기업: 알테오젠, 대웅제약
- 기준: 연결재무제표(CFS)
- 주요 분석연도: 2024~2025년
- 재고자산회전율 계산에는 2023년 말 재고자산도 활용
- 데이터 출처: 금융감독원 OpenDART

## 3. 재무지표

| 지표 | 계산식 |
|---|---|
| 매출 증가율 | (당기 매출액 / 전기 매출액 - 1) × 100 |
| 영업이익률 | 영업이익 / 매출액 × 100 |
| 재고자산 증가율 | (당기 기말재고 / 전기 기말재고 - 1) × 100 |
| 재고자산회전율 | 매출원가 / 평균재고자산 |
| 무형자산 비중 | 무형자산 / 자산총계 × 100 |

## 4. 검토 규칙

| 규칙 | 적용 조건 | 관련 회계기준 |
|---|---|---|
| INV-01 | 재고 증가율과 매출 증가율의 차이가 15%p 이상 | K-IFRS 제1002호 |
| INV-02 | 재고자산회전율이 전년 대비 5% 이상 하락 | K-IFRS 제1002호 |
| REV-01 | 매출 증가율 50% 이상 | K-IFRS 제1115호 |
| INT-01 | 총자산 대비 무형자산 비중 15% 이상 | K-IFRS 제1038호 및 제1036호 |

위 임계값은 학습용으로 설정한 값이며, 회계기준이나 감사기준의 공식적인 위험 판정 기준이 아니다.

## 5. PBC 추천 방식

탐지된 규칙 ID를 기준으로 사전에 작성한 PBC 목록을 연결한다.

각 추천 항목은 다음 정보를 포함한다.

- 관련 감사주장
- 요청할 자료
- 자료의 검증 목적
- 수행할 검증절차

추천 목록은 실제 감사에서 추가로 검토할 사항을 제안할 뿐, 해당 자료가 회사에 존재한다거나 감사인이 확보했다는 의미는 아니다.

## 6. 검증방법

- 필수 입력 열 누락 여부 확인
- 기업별 데이터 중복 여부 확인
- 경계값 및 결측값에 대한 단위 테스트
- 기존 결과와 신규 결과의 탐지 규칙 비교
- 연결·별도 재무제표 구분
- 공시자료의 회계기간 및 비교금액 확인

## 7. 주요 한계

1. 공개 공시자료만으로 실제 회계오류나 부정 여부를 확정할 수 없다.
2. 기업별 사업모델과 금액적 중요성을 탐지 기준에 충분히 반영하지 못한다.
3. 재무제표의 전체 무형자산과 개별 개발비는 구분해야 한다.
4. 일부 분석 입력 CSV에는 반올림된 수치가 포함되어 있어 경계값 부근에서 결과가 달라질 수 있다.
5. 현재 탐지 규칙의 민감도, 특이도 및 실제 감사상 유용성은 검증되지 않았다.
6. 단위 테스트는 프로그램 로직을 검증하며, 재무제표의 감사상 적정성을 보증하지 않는다.

**결론:** 본 프로젝트는 규칙 기반 재무정보 분석 및 감사 검토사항 추천 도구이며, 실제 감사의견을 제공하거나 회계오류를 판정하는 시스템이 아니다.
